# NIGHTFALL — 個人端末アプリ

スマートフォン向けの、厨二病な秘密組織風のタスク・プロファイリング管理アプリです。

## 起動方法
- `index.html` をブラウザで開くと利用できます。
- データは利用中のブラウザ内に保存されます。サーバーへの送信は行いません。
- よりアプリらしくホーム画面に追加するには、HTTPS対応のWebサーバーにこのフォルダを配置してください（GitHub Pagesなど）。iPhoneのSafariで開き、共有 →「ホーム画面に追加」を選びます。
- PWAのオフラインキャッシュは、HTTPSまたはlocalhost環境で動作します。

## 主な機能
- 司令室：ブリーフィング、成功率、階級、予言、緊急指令
- 任務管理：優先度、期限、作戦計画、成功条件、完了管理
- 人物分析局：対象ごとの観察記録。事実・発言・仮説を分離
- 極秘通信室：シーザー暗号、ROT13、反転、英数字モールス
- 機密文書庫：機密区分、本文の黒塗り表示
- 組織設定：組織名、コードネーム、紋章、バックアップ/復元

## 注意
- プロファイリングは入力した記録を整理する用途です。根拠のない人物評価やセンシティブな推測には使わないでください。
- 暗号機能は演出用の古典暗号です。秘密情報の保護には使わないでください。
- ブラウザデータを消去すると保存内容も失われるため、必要に応じてJSONバックアップを出力してください。
